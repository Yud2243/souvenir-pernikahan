# Direktori Foto Khusus Artikel (Blog)

Direktori ini (`assets/images/artikel/`) didedikasikan **khusus untuk aset foto artikel dan blog**.

## Panduan Pengelolaan & Pemisahan Foto:
1. **Pemisahan Total dengan Foto Produk:**
   - Seluruh halaman artikel (`blog/*.html`, `blog.html`, dan artikel preview di beranda/penulis) **hanya** boleh memuat foto dari folder `assets/images/artikel/`.
   - Jangan pernah menghubungkan file artikel ke folder `assets/images/produk/`.
2. **Duplikasi File Jika Foto Sama:**
   - Jika sebuah artikel membutuhkan ilustrasi foto dari suatu produk fisik, foto tersebut harus diduplikasi secara fisik dan disimpan di dalam folder `assets/images/artikel/`.
   - Mengubah, menghapus, atau mengompresi foto di folder ini tidak akan berdampak pada tampilan halaman produk/katalog.
3. **Format yang Disarankan:**
   - Format: `.webp`
   - Rasio rekomendasi: 16:9 atau 4:3
   - Resolusi: 600px - 1200px (dengan srcset responsif bila tersedia)
